# 🔢 로또 
## 📚 기능 목록

### 1. 로또 구입금액 입력 받기
- [x] `"구입금액을 입력해 주세요."` 메시지 출력
  - [x] 로또 구입 금액 입력
- 구입 금액 입력 예외 처리

---
### 2. 로또 구매 갯수
- [x] 로또 한장의 가격은 1,000원 `(구입 금액 / 1000 = 로또 발행 횟수)`
- 나머지가 생길 시 예외 처리

---
### 3. 로또 발행
- [x] `"%d개를 구매했습니다."` 메시지 출력
- [x] 로또 번호를 나타내는 6개의 랜덤 숫자, 범위(1 ~ 45), 중복 X
    - `Randoms.pickUniqueNumbersInRange(1, 45 ,6)`
- [x] 로또 발행 수 `ex) 8000원 구입 금액이면 8번 로또를 발행`
  - [x] 로또 번호를 리스트에 오름차순으로 저장
  - [x] 저장된 로또 리스트 출력
- 로또 번호 예외 처리

---
### 4. 당첨 번호 입력 및 파싱
- [x] `당첨 번호를 입력해 주세요.` 메시지 출력
- [x] 당첨 번호 입력
- 당첨 번호 입력 예외 처리


- [x] 당첨 번호를 쉼표(,)를 구분자로 분리
- [x] 당첨 번호 저장 (문자열 -> 정수형)
- 파싱 예외 처리

---
### 5. 보너스 번호 입력
- [ ] `보너스 번호를 입력해 주세요.` 메시지 출력
- [ ] 보너스 번호 입력
- 입력 예외 처리

---
### 6. 로또 당첨 통계
- [ ] `"당첨 통계"` 메시지 출력
- [ ] `---` 메시지 출력
- [ ] 로또 번호와 당첨 번호 비교하여 일치한 번호 수 구하기
- [ ] 일치한 번호 수가 1등 ~ 5등 중에 해당하면 해당 등수 +1
  - ex) 비교 결과 3개 일치이면 5등 개수 0 -> 1 증가
- [ ] 수익률 구하기 -> `수익의 총액 / 구입 금액 = 수익률`
  - [ ] 둘째 자리에서 반올림

---
### 7. 로또 당첨 결과 출력
- [ ] 당첨 내역 메시지 출력
  ```text
  3개 일치 (5,000원) - %d개
  4개 일치 (50,000원) - %d개
  5개 일치 (1,500,000원) - %d개
  5개 일치, 보너스 볼 일치 (30,000,000원) - %d개
  6개 일치 (2,000,000,000원) - %d개
  ```
- [ ] `"총 수익률은 %d%입니다."` 메시지 출력

---
### ⚠️ 예외 처리
**에러 메시지 출력 후, 입력을 다시 받는다**
- 에러 메시지 예시: `[ERROR] 로또 번호는 1부터 45 사이의 숫자여야 합니다.`

> **`구입금액 입력` 예외 처리**
> - [x] 입력값이 비어있는지 `StringUtils.isBlank()`
> - [x] 입력값이 숫자인지 (정규표현식 사용하여 양수만 해당)
> - [ ] 구입금액 입력값이 정수형 범위를 넘었는지 (예시: 9999999999999)
> - [x] 구입 금액 % 1000 = 나머지 값 존재 시 예외

> **`6개의 랜덤 로또 번호` 예외 처리**
> - [x] 로또 번호가 6개인지
> - [x] 로또 번호 6개가 중복이 아닌지
> - [x] 로또 번호가 1 ~ 45 사이인지

> **`당첨 번호 입력` 예외 처리**
> - [x] 입력이 비어있는지

> **`당첨 번호 파싱 후` 예외 처리**
> - [ ] 문자열 리스트 -> 길이(사이즈)가 6인지
> - [ ] 문자열 리스트 -> 정수형 리스트 변환 시 숫자에 해당하는지
> - [ ] 1 ~ 45 범위에 속하는지
> - [ ] 번호가 중복인지 -> `equals()`, `hashCode()` 객체간 값 비교

> **`보너스 번호 입력` 예외 처리**
> - [ ] 입력값이 비어있는지
> - [ ] 숫자인지
> - [ ] 1 ~ 45 범위에 속하는지
